# Executables the initrd takes the DT_NEEDED closure of.
#
# One path per line, relative to the rootfs. Text after '#' is a comment.
#
# The non-obvious entries:
#   mount, umount   systemd's built-in ExecStart/ExecStop for .mount units; no
#                   unit file mentions them, so no scan finds them, and without
#                   mount every API VFS mount (including the verity /usr) fails
#                   while the boot still looks healthy.
#   sulogin         the emergency shell's login prompt; failed-boot path only.
#   touch, flock    ExecStartPost of several oneshots; flock is the wrapper
#                   systemd-tmpfiles and systemd-sysusers run through.
#   mkdir           creates the /etc/systemd/system confinement mount.
#   mountpoint      ditto; a non-zero exit is a fail-closed check.
#   udevadm         populates /dev.
#   printf, cat, ls, sync
#                   exec'd by absolute path and linked by nothing, so the
#                   closure walk cannot see them. A missing /usr/bin/printf made
#                   vngrd-provision.service fail before enrolling anything, with
#                   the console naming only the unit.
#   systemd-pcrextend
#                   the PCR 11 phase barrier behind systemd-pcrphase-initrd.
#                   Without it enter-initrd is never measured and the TPM never
#                   unseals the root.
#   systemd-ask-password
#                   what systemd-cryptsetup execs for a passphrase: the initrd's
#                   fallback when the TPM cannot release the key.
#   vngrd-cmdline-guard
#                   checks that /proc/cmdline is the one the signed UKI's .cmdline
#                   says (/.extra/signed-cmdline). Two files and a compare, no TPM
#                   and no crypttab, and it is the runtime half of the stub patch
#                   that stops an SMBIOS Type 11 OEM string from appending to a
#                   signed command line. Without it an unsigned host-injected
#                   usrhash= names a different /usr verity pair and nothing in the
#                   boot notices.
#
# No shell: usr/bin/sh is a symlink to fish (12M) and /bin/sh does not exist in
# a merged-/usr rootfs. No module machinery either: the kernel is CONFIG_MODULES=n.
